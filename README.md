# Галереи ACSM

Единый сайт: `/` — выбор галереи, `/cosmic-frontiers/` и `/earth-explorers/` — существующие интерактивные справочники. Содержимое карточек вынесено в `content/*.json`. Панель `/admin/` редактирует поля и сохраняет изменения в GitHub.

## Подключение

1. Создайте репозиторий GitHub и загрузите содержимое этой папки в его корень.
2. В `admin/config.yml` замените `OWNER/REPOSITORY` на адрес созданного репозитория (например, `museum/gallery-training`).
3. В Netlify создайте сайт **Import from Git**, выберите этот репозиторий, оставьте Build command пустым, Publish directory укажите `.`.
4. Откройте `/admin/`, войдите через GitHub и откройте галерею. Возможен вход с GitHub access token; токен вводится в панели, его нельзя вставлять в файлы сайта. Пользователю нужны права записи в репозиторий.
5. После сохранения Netlify автоматически публикует новую версию.

Для локальной проверки из этой папки запустите `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Открытие страниц прямо как `file://` блокирует загрузку JSON в большинстве браузеров.

Встроенные схемы и концептуальные изображения сохранены в страницах. Для CF изображения также хранятся в JSON; большие поля изображений в редакторе лучше не менять вручную. Изменение структуры игр и схемы требует разработки.
