Cosmic Frontiers

Экспонаты и образовательные идеи

Справочник по материалам галереи. Код, название, действия посетителя и учебная задача взяты из образовательной матрицы; раскрываемые тексты панелей отмечены своим источником. Изображения из концептуальной презентации показывают проектный вид.

В материалах есть разные списки космонавтов для CF1: презентация называет Айдына Аимбетова, образовательная матрица — Светлану Савицкую. Здесь списки не объединяются; для конкретного содержания используются подписанные тексты официальных панелей.

План галереи

Основа — план из концептуальной презентации, с расположением зон. Точные позиции отдельных экспонатов пока не отмечены в предоставленном плане. Выберите зону, затем код в списке; карта не утверждает место каждого экспоната.

План и рендеры концептуальные: окончательный вид и размещение могут отличаться.

Проверка знаний

Шесть раундов по кодам, зонам, изображениям, действиям и образовательным задачам. В каждом раунде вопросы без повтора; повторный запуск начинает новый счёт.
